# Inventario de capacidades futuras

Capacidades pendientes de validación de producto, modelo o servicio. Las pantallas del MVP se limitan a entradas declaradas y resultados disponibles.

| Área | Capacidad futura |
| --- | --- |
| Cartografía | Edición avanzada, KML, GeoJSON y shapefiles, NDVI y zonificación de ambientes |
| Manejo | Rotaciones personalizadas y ajuste libre de fechas con recálculo |
| Suelo y nutrición | Balances nitrogenados, recomendaciones de fertilización, materia orgánica y erosión cuantitativa |
| Economía | Sensibilidad y flujo de caja avanzados |
| Modelos | Análisis probabilístico y simulaciones agronómicas ampliadas |
| Operación | Monitoreo offline, sensores y estaciones meteorológicas |
| Colaboración | Colaboración entre usuarios e historial de versiones |
